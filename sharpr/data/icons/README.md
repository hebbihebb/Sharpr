# Sharpr symbolic icons

Original geometric artwork created for Sharpr during Phase 9 (2026).
Source: the editable SVG files in `scalable/actions/`; no third-party artwork.
All seven `sharpr-*-symbolic.svg` files are dedicated to the public domain
under CC0 1.0: https://creativecommons.org/publicdomain/zero/1.0/.
The app uses system symbolic icons for standard actions.
