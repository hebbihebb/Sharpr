# JetBrains Mono

Unmodified variable fonts from [JetBrains Mono v2.304](https://github.com/JetBrains/JetBrainsMono/tree/v2.304/fonts/variable), licensed under the [SIL Open Font License 1.1](OFL.txt).
Copyright 2020 The JetBrains Mono Project Authors.

The upright and italic files cover weights 100–800. They are embedded,
together with the licence, in Sharpr's GResource. Pango registers them for
this process only, from anonymous memory-backed files; no desktop font
installation or runtime download is needed. CSS prefers `JetBrains Mono`.

Sources (downloaded at development time, never by the app):

- `JetBrainsMono.ttf`: [upstream](https://raw.githubusercontent.com/JetBrains/JetBrainsMono/v2.304/fonts/variable/JetBrainsMono%5Bwght%5D.ttf)
- `JetBrainsMono-Italic.ttf`: [upstream](https://raw.githubusercontent.com/JetBrains/JetBrainsMono/v2.304/fonts/variable/JetBrainsMono-Italic%5Bwght%5D.ttf)
- `OFL.txt`: [upstream](https://raw.githubusercontent.com/JetBrains/JetBrainsMono/v2.304/OFL.txt)
